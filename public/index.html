    About CFUpload

    CFUpload is a lightweight, open-source tool designed to bridge the gap between a user-friendly web interface and Cloudflare's R2 Object Storage. It allows you to transform a Cloudflare Worker into a self-hosted file management system with a static frontend.

    Features

    CFUpload streamlines your storage workflow by offering an intuitive suite of tools designed for speed and simplicity.
